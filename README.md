# 👋 Hi，我是 Tina

## 關於我

我是一名具備 iOS、Android 與 IoT 介面設計經驗的**UI/UX 設計師**。
熟悉 Figma、Human Interface Guidelines（HIG）與 Material Design，能從使用者需求與產品流程出發，完成 User Flow、Wireframe、Prototype 到高擬真 UI 設計。
目前持續學習前端開發，致力於將 UI/UX 設計與實際前端實作結合，建立兼具良好使用體驗與工程可行性的數位產品。

### 實務經驗

- 跨平台 UI/UX：熟悉 iOS、Android 與 IoT 產品設計流程
- IoT 產品設計：具備裝置控制、設備管理、狀態監控與情境自動化介面設計經驗
- UX/UI 設計：能規劃 User Flow、Wireframe、Prototype 與高擬真介面
- 設計規範：熟悉 HIG、Material Design 與跨平台介面規範
- 設計品質管理：進行 UI/UX 規格檢核，提升介面一致性、可用性與開發品質
- Design QA：檢核 Typography、Icon、Layout、Component 與實際開發成果，降低設計與實作落差
- Design System：維護元件、Typography、Spacing、Icon 與介面一致性規範
- Design Handoff：與工程師確認 UI 規格、互動狀態、Responsive 與實作細節，協助設計順利落地
